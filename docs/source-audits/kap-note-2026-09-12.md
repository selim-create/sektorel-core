# KAP source note — 2026-09-12

KAP is a canonical candidate for the `sirketler-yatirimlar` desk, but it is intentionally not implemented in the KOSGEB/Sanayi adapter batch.

KAP documents an official Veri Yayın Servisi REST API for data-distribution use. That service has authorization/subscription requirements and is the appropriate path for high-volume requests. Sektörel Ajanda should not build a high-volume scraper around undocumented/public-internal KAP endpoints as a substitute for that service.

Next step: design a separate compliant KAP integration mode (licensed API when available, or explicitly bounded low-volume/manual discovery after a dedicated access/terms review).
